# 🚀 CSE Advanced Financial Analyzer

කොළඹ කොටස් වෙළෙඳපොළ (CSE) වාර්තා තත්පර කිහිපයකින් විශ්ලේෂණය කර දත්ත Excel ගොනුවක් ලෙස ලබාගන්න. 

### 🌟 Features
- **Dual AI Engine:** Google Gemini Pro සහ Groq Cloud (Llama 3) යන දෙකම පාවිච්චි කළ හැක.
- **Deep Extraction:** EPS, NAV, PE, ROE, PBV සහ තවත් මූල්‍ය දත්ත රාශියක් ස්වයංක්‍රීයව පෙරහන් කරයි.
- **One-Click Export:** සියලුම දත්ත සාරාංශයක් ලෙස Excel ගොනුවකට බාගත කළ හැක.

### 🛠️ පාවිච්චි කරන ආකාරය (How to Use)
1. **API Key එකක් ලබාගන්න:** - Gemini සඳහා: [Google AI Studio](https://aistudio.google.com/)
   - Groq සඳහා: [Groq Console](https://console.groq.com/)
2. **Key එක ඇතුළත් කරන්න:** ඇප් එකේ Sidebar එකට ගොස් ඔබ ලබාගත් Key එක ලබා දී AI Engine එක තෝරන්න.
3. **Report එක Upload කරන්න:** ඕනෑම CSE Annual හෝ Quarterly PDF වාර්තාවක් ඇතුළත් කරන්න.
4. **Download:** "Analyse" වූ පසු ලැබෙන Excel ගොනුව බාගත කරගන්න.
